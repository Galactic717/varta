# VARTA

**Live air-threat map of Ukraine with a question-answering agent that cannot make facts up.**
Ask in Ukrainian — "where is the nearest Shahed?", "is anything heading to me?", "when will it reach me?" —
and get an answer computed from live open data (NEPTUN, MAPA.UA, official air-raid alerts).
A fine-tuned mmBERT-small only classifies the question into one of 12 intents; distances, bearings, ETA and
alert status are computed by plain code and rendered by templates, so the model never sees the data and never
writes the answer. Selected by a measured bake-off on 436 held-out, hand-labelled questions: mmBERT-small 89.7 %,
char-n-gram 88.8 %, Qwen3.5-0.8B few-shot 58 %, GPT-2 3.7 %. The map follows NEPTUN's visual language
(satellite basemap, raion alert fills, white target silhouettes). Personal project, not an official warning system.

---

Особиста карта повітряних загроз України з агентом, якого можна питати текстом: «де найближчий шахед?»,
«чи летить щось на мене?», «коли буде у мене?», «чи є тривога у Львові?». Для себе, родини й друзів.
**Не офіційна система оповіщення — завжди реагуйте на сирену.**

Дані: [Карта повітряних тривог — NEPTUN](https://neptun.in.ua/) (основне джерело, WebSocket),
[MAPA.UA](https://mapa.ua/) (свіжі обʼєкти й сліди), офіційні тривоги по районах — з NEPTUN.
Місця — GeoNames (CC-BY 4.0), підкладка — Esri World Imagery, OpenFreeMap / © OpenStreetMap.

## Запуск

```bat
py -3.11 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python tools\fetch_model.py                      :: mmBERT (~540 МБ) з GitHub Release; без нього — легка модель
.venv\Scripts\python main.py                                   :: карта на http://127.0.0.1:8080/
.venv\Scripts\python main.py ask "де найближчий шахед" --place "Київ"   :: питання з терміналу
.venv\Scripts\python -m pytest                                 :: тести
```

Налаштування — змінні середовища або `.env`: `VARTA_HOST`, `VARTA_PORT`, `VARTA_MAPA=0` (вимкнути MAPA),
`VARTA_OFFLINE=1`, `VARTA_LOG_EVENTS=0`, `VARTA_HOME="50.45,30.52,Дім"` (місце для CLI),
`VARTA_MODEL=intent_ngram` (легкий класифікатор для слабкого ПК: без torch, ~20 МБ RAM замість ~1.3 ГБ).

Межі районів (NEPTUN) і довідник міст MAPA завантажуються при першому запуску. Газетир (`data/geo/places.json`,
GeoNames CC-BY 4.0) уже в репозиторії; перебудова — `tools/build_gazetteer.py`. Архів атак MAPA для
`tools/eval_forecast.py` — `tools/fetch_archive.py`.

Основна модель (mmBERT) потребує `torch` і `transformers`; карта стартує одразу, а агент перемикається з правил
на модель, щойно та завантажиться (~20 с з USB-диска).

## Як влаштовано

```
NEPTUN WS ──┐                                ┌─► /api/state ─► карта (MapLibre, стиль як у NEPTUN)
MAPA.UA ────┼─► Situation (злиття, свіжість) ─┤
тривоги ────┘          │                      └─► /api/ask ─► Agent
                       └─► data/log (власний архів фреймів NEPTUN)

Agent: питання ─► маскування (газетир, лексикон) ─► класифікатор наміру ─► Executor (код) ─► шаблон UA
```

**Головне правило: модель розуміє питання, код рахує відповідь.** Класифікатор бачить лише замасковане питання
(«що летить на <місце>?») і обирає один з 12 намірів. Він не бачить даних і не пише текст відповіді, тож
вигадати відстань, місто чи тривогу не може. Місто береться лише з газетира (27 631 населений пункт з
відмінками: «у Кривому Розі», «над Білою Церквою», «на Харківщину»), числа — з треків, тривоги — з NEPTUN.

### Яка модель і чому

Задача моделі — зрозуміти, *про що* питають (12 намірів: найближча ціль, що біля місця, чи летить на місце,
коли буде, тривога, обстановка, скільки, чи безпечно, довідка, допомога, відмова, балачки). Для цього
порівняно 6 кандидатів на питаннях, яких модель не бачила:

* **тест C** — 436 питань, які написала локальна Gemma-4-26B «від імені» різних людей (суржик, капс, емодзі);
  мітки виставлено вручну *до* будь-яких прогонів моделей (мітки Gemma були хибні в 13–44 % випадків);
* **ручний** — 115 питань, написаних до навчання (той самий автор, що й шаблони, тому оцінка завищена);
* **dev B** — на ньому аналізувались помилки, тому чесним тестом він уже не є.

| модель | тест C | ручний | мс/питання |
|---|---|---|---|
| **mmBERT-small (JHU, 2025), fine-tune** — у роботі | **89.7 %** | **98.3 %** | 42 (CPU) |
| char-n-gram + LogReg — легкий варіант (`VARTA_MODEL=intent_ngram`) | 88.8 % | 95.7 % | 0.07 |
| MiniLM-L12 + LogReg | 71.1 % | 90.4 % | 3.9 |
| правила (ключові слова) | 59.6 % | 71.3 % | 0.04 |
| Qwen3.5-0.8B, few-shot (генеративна LLM) | 58.0 % | 71.3 % | 309 (GPU) |
| GPT-2 small, few-shot | 3.7 % | 8.7 % | 40 |

Висновки, без рожевих окулярів:
* Генеративні LLM до 1B для цієї задачі — найгірший вибір: Qwen3.5-0.8B не кращий за ключові слова і в сотні
  разів повільніший. GPT-2 української не знає взагалі (гірше за випадкове вгадування, 8.3 %).
* mmBERT і n-gram статистично нерозрізнені на тесті C (McNemar p = 0.65): mmBERT краще тримає незвичні
  формулювання, n-gram у 600 разів швидший і не потребує torch. Ансамбль дав +0.7 п. — у межах шуму, не взято.
* ~10 % помилок, що лишились, — переважно межа «безпечно / балачки» і «летить на / що біля». Ціна такої помилки
  невелика: обидві відповіді беруть ті самі факти й завжди додають рядок офіційної тривоги.

Повні цифри: `docs/intent_bakeoff.json`, `models/intent/report.json`. Відтворення:
`tools/gen_intents.py` → `tools/intent_bakeoff.py` → `tools/train_intent.py`.

### Прогноз «чи підлетить»

Перевірено на архіві 255 атак MAPA.UA (`tools/eval_forecast.py`, 1.9 млн пар «ціль–місце»): Brier 0.064
проти 0.213 у базової частоти (у 3.3× краще). Підбір σ на цих даних дав 10°, але маршрути MAPA — прямі
інтерполяції, тож зменшувати σ означало б зробити живий прогноз самовпевненим; лишено обережні 20°/35°.
Справжнє калібрування — після накопичення власного архіву фреймів NEPTUN (`data/log`, пишеться з 25.10.2026).

## Чесні обмеження

* Радарів немає: усі незалежні карти (і ця) живуть на Telegram-каналах і офіційних тривогах. Позиції — оцінки з затримкою.
* Прогноз «чи підлетить» — фізика: прямий курс з похибкою σ (20° з відомою швидкістю, 35° з припущеним курсом).
  Шахеди маневрують — тому агент завжди додає «курс може змінитися» і рядок офіційної тривоги.
* Агент не відповідає про влучання, наслідки й роботу ППО (ст. 114-2 ККУ) і ніколи не каже «безпечно».
* Назви місць у відповідях не відмінюються («біля н. п. Вільнянськ») — неправильний відмінок гірший за канцелярит.
* Telegram/Discord ще не підключені — свідомо.
